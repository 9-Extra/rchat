# 用于AIRP的后端

SillyTavern过于复杂，并且对工具调用的支持很糟糕，所以需要一个简单版的SillyTavern，运行后启动一个后端并打开网站，和AI对话
为AI提供持久化代码环境，一个工具解决变量更新，复杂计算和状态记录的问题
本项目不兼容SillyTavern格式的预设和角色卡，而是使用一个简化的版本

# 用法

1. 配置 API key：复制 `config.yaml.example` 为 `config.yaml`，将 `api_key` 替换为你的真实 key。
2. 启动服务器：
   ```bash
   uv run -m main
   ```
   默认在端口 25530 上启动双栈访问的服务器，并自动打开浏览器。

测试时可使用 `uv run -m main --port 25531 --no-browser` 避免与主实例冲突。

# 预设和角色卡
这两个概念来自SillyTavern，但本项目将它们大幅度简化

预设：功能上是在不同的世界观定义间通用的AI主持指南，定义的通用的文风，禁词表，防止全知等。逻辑上预设控制了如何基于对话历史和角色卡构造最开头的输入模型的上下文，包含系统提示词。
角色卡：功能上它的作用已经远超“定义单个角色”，或者把它叫“规则书”更合适，定义了具体的世界背景，很多人物以及故事背景，开局等等。但逻辑上来说就是几个大字符串，预设决定将它插到上下文的什么地方。我们不搞关键词匹配这类复杂规则，在现在模型上下文足够长且缓存命中价格远低于输入价格的情况下，破坏上下文前缀的损失>>>缩短输入带来的收益。

# 对话页面
支持回滚和历史修改，在AI块右上显示一行按钮，可以修改AI的输出（影响之后发给AI的上下文，但不管已经输出的内容），或者重新输出（让AI再输出一次）。在用户输入块右上显示回滚按钮，撤销包括此次回复在内的所有后续对话轮次并将此次回复放入输入框方便修改。
支持流式输出，思考块默认折叠，即使输出内部是工具调用的内容。

提供一个上下文预览功能，打开一个新的页面展示将发送给AI的完整提示词上下文，需要包含输入框中的本次输入（这样才知道输入被拼在哪里，即被拼在工具调用内部）。
支持切换session和预设，支持指定角色卡和预设创建session。session内可以切换预设，但不能切换角色卡。
指定角色卡并创建一个新的session后，开局会显示为一个特殊的输出块，支持选择开局（或者一个“空开局”），支持像其它AI输出一样修改开局。开局块是用户对话界面的第一个块（可能是空的）。点击开始后AI产生第一轮输出，之后对话正式开始。

# 历史保存
对话历史以jsonl格式保存在./sessions/{name}文件夹下，其它需要保存的状态以json格式保存在同目录下另一个文件中

# 工具

world_run: 在持久的 Python 环境中执行一段代码，用于一切涉及数值与规则的判定与状态更新。
read_file: 读文件
respond: 提交剧情选项供用户参考
