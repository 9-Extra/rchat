# 用于AIRP的后端

一个究极简化版的SillyTavern，运行后启动一个后端并打开网站，和AI对话

为AI提供持久化代码环境，一个工具解决变量更新，复杂计算和状态记录的问题 

本项目不兼容SillyTavern格式的预设和角色卡，而是使用简化的版本

# 用法

1. 配置 API key：复制 `config.yaml.example` 为 `config.yaml`，将 `api_key` 替换为你的真实 key。
2. 启动服务器：
   ```bash
   uv run -m main
   ```
   默认在端口 25530 上启动双栈访问的服务器，并自动打开浏览器。

# 预设和角色卡
这两个概念来自SillyTavern，但本项目将它们大幅度简化

预设：功能上是在不同的世界观定义间通用的AI主持指南，定义的通用的文风，禁词表，防止全知等。逻辑上预设控制了如何基于对话历史和角色卡构造最开头的输入模型的上下文，包含系统提示词。

角色卡：功能上它的作用已经远超“定义单个角色”，或者把它叫“规则书”更合适，定义了具体的世界背景，很多人物以及故事背景，开局等等。但逻辑上来说就是几个大字符串，预设决定将它插到上下文的什么地方。没有关键词匹配这类复杂规则，在现在模型上下文足够长且缓存命中价格远低于输入价格的情况下，破坏上下文前缀的损失>>>缩短输入带来的收益。

提供一个极简的默认预设（弱破限）和一张乱搓的角色卡。具体格式见AGENTS.md

# 对话页面
支持回滚和分支，AI输出修改，重Roll。
流式输出，思考块和工具调用默认折叠。
提供上下文预览功能（类似dsh的轨迹），完整展示将发送给AI的完整提示词上下文，包含输入框中的本次输入。
支持切换session和预设，支持指定角色卡和预设创建session。session内可以切换预设，但不能切换角色卡。

# 历史保存
对话历史以jsonl格式保存在./sessions/{name}文件夹下，其它需要保存的状态以json格式保存在同目录下另一个文件中

# 工具设计

world_run: 在持久的 Python 环境中执行一段代码，用于一切涉及数值与规则的判定与状态更新。这允许我们在卡中设计复杂的数值计算和真正的随机掷骰。
read_file: 读文件，这允许我们把卡组织成一组外部文档让AI自主选读，卡里只用放目录+索引，而不是全量塞入上下文。
respond: 提交剧情选项供用户参考，经测试几乎不会遗忘，稳定出选项
